# vsacictl
This package handles vsacictl command line tool. This is an image that will contain all the dependencies required for vsa-control plane cicd.

Cadence of PR builds, weekly RC cuts, and VSA/ONTAP image copy (separate from VCP software builds): [doc/guides/ci-cd-build-process.md](../doc/guides/ci-cd-build-process.md).
